# Project Context

Keep under 800 words.

## Goal
Consolidate six prototype webpage games into a single-page browser game.

## Scope
- In: 2D Physics
- Out: 3D Graphics, non-free libraries

## Constraints
- Devices: Android phone + 4 GB Chromebook
- Budget: free tiers only unless approved

## Definition of done
- Free of bugs, polished look and feel, some form of multiplayer

## Current state
- Repo scaffolded for 6 prototypes (`One`, `Two`, `Four`, `Six`, `Seven`, `Eight`): vanilla JS + canvas, Rapier2D 0.21.0 vendored (Apache-2.0), static server, smoke test. Prototypes analyzed; no game code merged yet.
