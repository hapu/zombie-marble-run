# AGENTS.md

Instructions for AI coding agents. Keep under 500 words.

## Before changing anything
1. Inspect the repo and working tree.
2. Read `PROJECT_CONTEXT.md`, `HANDOFF.md`, `TODO.md`, `docs/WORKFLOW.md`, and `WORKSHOP.md` if relevant.
3. Identify existing work to preserve.
4. Verify provider and tool facts from official sources if they may have changed.
5. Explain the plan briefly before any large restructuring.

## Rules
- Stay provider agnostic.
- Don't invent quotas, capabilities, or compatibility claims.
- Don't delete existing work without explicit approval.
- Never expose or commit credentials.
- Small, reviewable commits.
- Don't assume another assistant's work is correct; check the files.
- No paid usage without approval.

## When you finish, report
- Files changed, and what and why.
- Checks run and results.
- Known limitations or open questions.
- Branch and commit info.
- Next recommended task.

Then update `HANDOFF.md`.
